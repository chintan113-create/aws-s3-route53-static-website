# AWS S3 + Route 53 Static Website

## Project Overview

I deployed a static website on AWS using Amazon S3 and configured Amazon Route 53 for DNS.

## AWS Services Used

- Amazon S3
- Amazon Route 53

## What I Did

- Created an S3 bucket
- Uploaded the website files to S3
- Configured the S3 bucket for static website hosting
- Configured Route 53 for DNS
- Connected the domain to the S3-hosted website
